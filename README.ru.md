# MetaCheck Web

English version: [README.md](README.md).

Веб-версия [MetaCheck](https://github.com/v1lb/metacheck): показывает, что выдаёт фото или видео (EXIF, GPS, XMP, IPTC,
текстовые блоки PNG, Content Credentials / C2PA, теги MP4/MOV), ищет в метаданных следы ИИ-генерации и сохраняет копии
с удалёнными или исправленными метаданными. Всё работает в браузере: файлы никуда не загружаются.

Статический сайт без сборки и зависимостей: обычные ES-модули, GitHub Pages отдаёт их как есть.

## Возможности
- Проверка файла перетаскиванием, через диалог или вставкой из буфера: JPEG, PNG, WebP, GIF, HEIC, AVIF, MP4, MOV.
- Признаки ИИ только по метаданным: манифест C2PA (читается, подпись не проверяется), IPTC DigitalSourceType, параметры
  генерации (A1111, ComfyUI, NovelAI, Fooocus, InvokeAI), около 70 названий генераторов.
- Индекс приватности (0–100) с реальными значениями, GPS-щит, просмотр метаданных с поиском и экспортом CSV, схематичная
  офлайн-карта; тайлы OpenStreetMap загружаются только по кнопке.
- Очистка без пережатия: JPEG, PNG, WebP, GIF, HEIC/AVIF (на месте), MP4/MOV (Pro). Каждый результат проверяется.
- Удаление только GPS (JPEG, PNG, WebP, HEIC, AVIF), редактор EXIF для JPEG, пакетная очистка в ZIP, проверка папки,
  пакетный сдвиг даты (Pro).
- История отчётов и статистика в локальном хранилище браузера; экспорт текстом, печать/PDF и JSON, отправка JSON-отчёта
  в свой API (Pro).
- Русский и английский, светлая и тёмная темы.

Бесплатно: до 10 очищенных фото в сутки (UTC), 5 за пакет, 10 отчётов в истории. Pro включается лицензионным ключом
(`MC1.…`), теми же ключами, что в приложении для Android (там их выпускает `tools/license_tool.py`).

## Отличия от приложения для Android
- Очистка не перекодирует пиксели (браузер пересохраняет картинку только как запасной путь для файлов с нестандартной структурой).
- Нет покупки через Google Play, камеры и перезаписи оригинала: браузер всегда скачивает новую копию.
- «Сохранить PDF» открывает диалог печати браузера.
- Ключ API хранится в локальном хранилище без шифрования; сервер API должен разрешать CORS-запросы с сайта.

## Структура
```
index.html, css/app.css      оболочка страницы и стили
js/core/                     парсеры, очистка, редактор, правила признаков: без DOM, работает и в Node
js/i18n/                     en.js, ru.js: строки, общие с приложением; web.js: строки сайта
js/ui/                       экраны (главная, отчёт, студия, настройки), карты
js/store.js, js/ops.js       локальное хранилище, лимиты тарифа, операции с файлами
tests/                       тесты для Node и тестовые файлы
```

## Разработка
```
npm test                      # node --test, Node 20+
npm run serve                 # http://localhost:8080
python3 tests/make_fixtures.py   # пересобрать тестовые файлы (Pillow, ffmpeg)
```

## Публикация
GitHub → Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Сайт появится по адресу
`https://v1lb.github.io/mc-web/`. Pages для приватного репозитория требует платного тарифа GitHub; иначе репозиторий нужно сделать публичным.
